App-loto  Lô Tô (Vietnamese Bingo) Desktop Game

A desktop game based on Lô Tô (Vietnamese Bingo). Numbers are called out one by one — the first player to complete a full row of 5 numbers on their card wins.

 Features
 Numbers are called out automatically during gameplay
 Players mark called numbers on their card
 First player to complete a row of 5 numbers wins
 Tech Stack

C#, .NET, WinForms/WPF

Getting Started

Open the solution file (.sln) in Visual Studio, restore NuGet packages if prompted, and press Start to run the app.
